Task (US-016): Embedded TUI: Direction Stack and Workspace Settings Views
Implement Direction Stack and Workspace views in ~/.pi/agent/extensions/rorca/tui/direction-view.ts and ~/.pi/agent/extensions/rorca/tui/workspace-view.ts. Direction view shows L1-L3 layers with editable content dispatching to PUT /api/direction. Workspace view lists registered workspaces with health scores and allows switching the active workspace in the Pi session.

## Context
- **API endpoints already exist**: `GET /api/direction?workspaceId=`, `PUT /api/direction`, `GET /api/workspaces`, `GET /api/workspaces/:id/health` are all implemented in `backend/src/routes/`. No backend changes needed — this is purely a TUI client.
- **Direction Stack structure**: `GET /api/direction` returns `{ layers: [{ layer: 1, content: "..." }, { layer: 2, ... }, { layer: 3, ... }] }`. L4/L5 are NOT stored in `direction_layers` table (they come from spec brief/story annotations), so only L1–L3 are editable here.
- **Health score components**: The health endpoint returns weighted scores from `workspace-echolocation.ts`: CLAUDE.md (30pt, half credit if <10 lines), AGENTS.md (20pt), config.json (20pt), MEMORY.md (15pt), Skills (15pt). Match the AC display format exactly.
- **Auth handling**: Backend auth is globally bypassed for local single-user mode, but the TUI must still handle 401/403 gracefully since the backend may not be running or the token may be invalid. Use the `token` parameter for MCP Bearer auth header (`Authorization: Bearer ${token}`) per CLI-045.
- **N+1 avoidance for health scores**: AC specifies "batch lazy-loaded on first focus" — fetch health only when a workspace row is first focused/selected, cache the result in memory for that view session. Do NOT fetch all health scores on initial load.
- **Extension file location**: Files go in `~/.pi/agent/extensions/rorca/tui/` — this is the Pi extension directory structure. Follow the same patterns as other files in that directory (import ExtensionAPI type, use `pi.ui` for rendering, `pi.fetch` or raw fetch for API calls).
- **Terminal raw mode editor**: The inline text editor (Ctrl+S save, ESC discard) must use `process.stdin.setRawMode(true)` with a readline interface. Ensure cleanup on exit — restore raw mode state and re-render the parent view on both save and discard paths. This is a common source of terminal corruption bugs if not handled properly.
- **Workspace path truncation**: AC specifies truncation from the LEFT for paths >40 chars (e.g., `...ce/rorca`). Use a helper like `path.length > 40 ? '...' + path.slice(-37) : path`.
