# Security Policy

## Supported versions

We patch the current mainline and active release branches when practical.

## Reporting a vulnerability

Please report security issues privately to:

**security@rorca.app**

Include:
- what you found
- impact
- reproduction steps
- affected surface

## Safe handling guidance

- Do not include secrets in bug reports.
- Redact tokens, keys, and personal data in screenshots.
- Prefer minimal repros.

We’ll acknowledge reports and coordinate a fix or mitigation.
